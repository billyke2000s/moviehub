# Website and playback-provider audit — 26 October 2026

This is a live HTTP inspection of all **63 bundled public websites**, including the 26 previously excluded sites, using the exact configured addresses. The first sweep made 111 homepage/search requests; follow-up requests inspected current detail pages, player selectors, JavaScript and public player APIs. These checks used this workspace's supplied network proxy, not a physical TV. A failed request is an observation from this network, not proof that a domain has permanently closed.

The Kodi library and FilePursuit modules are also bundled; they are local-library and API-key integrations rather than anonymous public websites. They remain outside website discovery.

## What counts as evidence

- HTTP 200 alone does not establish a working catalogue. Parking, advertising, gambling redirects and empty pages are recorded explicitly.
- A working catalogue/search does not establish working playback. Host extraction, media validation and actual TV playback are separate stages.
- A title missing from a specialist catalogue does not establish a broken scraper. Live provider outcomes remain title- and location-specific.
- No excluded site is re-enabled by this change. Existing adapters stay bundled for explicit audits; no additional site is removed based on an inconclusive request.

## Concrete playback inspection

Watch-TVSeries and TVids advertise 11 external players; TVSeries.video advertises seven. Their current Xpass player returns 32 named backends through a public, token-bound encrypted response. Fresh live checks decrypted that response and obtained two independent HLS master/child playlists and sample segments. One sampled backend returns MPEG-TS; another wraps TS in PNG. The VOD bridge now opts that observed flow into MovieHub's existing carrier decoder. These HTTP samples are not a claim of physical-TV playback or that all 32 backends work.

M4uHD's actual AJAX endpoint returned three player iframe URLs for Inception. Iwaatch's actual search and web-player protocol returned two quality-specific stream URLs after obtaining fresh page/challenge values. SeriezLoaded's obsolete search endpoint returned 410 despite its catalogue being live. The current search and landing page were inspected before adapting that scraper.

Each playable row now retains the website and actual source-provider identity. Different backends remain separate even when they resolve to the same CDN URL. The search-details panel also records separate host attempts; website progress still counts websites, not a guessed number of downstream sources. Failed or unsupported hosts are not represented as playable rows.

## Validation and outstanding evidence

Offline regressions exercise the actual provider methods against small current-structure fixtures: canonical links, M4uHD cards/AJAX, PressPlay active servers, nested selectors, Iwaatch year matching and issued challenge values, Xpass authenticated responses/backends, distinct host labels and redacted diagnostics. The Xpass AES-GCM fixture is produced with an independent implementation; tampering is rejected, including empty associated data.

The GitHub audit probes every bundled website with movie/episode capabilities, then probes the repaired sites with Inception. Only returned, validated media is counted. A green offline test, homepage or extracted iframe does not turn a failed live host into a working source. Runner results and unresolved host protocols must be reviewed before release. No APK has been published for this work.
